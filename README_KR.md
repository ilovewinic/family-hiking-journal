# 가족 산행기록장 (클라우드 동기화 버전)

기존 산행기록장의 화면과 기록 기능을 유지하면서 Supabase 클라우드 동기화, 가족 열람 전용 계정, 비공개 사진 저장을 추가한 버전입니다.

## 포함 파일
- `index.html`: 홈페이지 화면
- `styles.css`: PC/스마트폰 반응형 디자인
- `app.js`: 산행 기록, 사진, 검색, 백업, 로그인, 가족 권한
- `supabase-config.js`: Supabase 프로젝트 URL 및 anon/public 키 설정
- `supabase_schema.sql`: 데이터베이스와 보안 정책
- `manifest.json`: 스마트폰 홈 화면 추가 정보

## 먼저 알아둘 점
- Supabase와 GitHub Pages 무료 이용 범위 안에서 운영할 수 있습니다. 무료 요금제의 저장공간·대역폭·비활성 프로젝트 정책은 서비스 정책에 따라 달라질 수 있습니다.
- 이 패키지를 받았다고 클라우드가 이미 연결된 것은 아닙니다. Supabase 프로젝트 생성, SQL 실행, 설정값 입력, GitHub Pages 게시가 필요합니다.
- `service_role` 키는 절대 웹사이트 코드에 넣지 마세요. Supabase의 Project URL과 anon/public 키만 사용합니다.
- 최초로 가입하고 로그인한 계정이 관리자(기록 소유자)로 자동 등록됩니다. **관리자 계정으로 먼저 가입·로그인한 뒤 가족 계정을 가입시켜야 합니다.**
- 가족은 각자 계정을 만들고 이메일 인증을 마친 다음, 관리자가 홈페이지의 `가족 관리`에서 해당 이메일을 추가합니다.
- 가족은 기록과 사진을 볼 수만 있습니다. 작성·수정·삭제·사진 업로드 권한은 관리자에게만 있습니다. 이 권한은 화면뿐 아니라 Supabase 데이터베이스/사진 저장소 정책에서도 제한됩니다.

## 1. Supabase 프로젝트 만들기
1. https://supabase.com 에서 무료 프로젝트를 만듭니다.
2. 프로젝트가 준비되면 왼쪽 `SQL Editor`를 엽니다.
3. 이 패키지의 `supabase_schema.sql` 전체 내용을 붙여넣고 `Run`을 누릅니다.
4. `Project Settings` → `API`에서 `Project URL`과 `anon` 또는 `publishable` 공개 키를 확인합니다.
5. `Authentication`에서 Email 로그인 방식을 켭니다. 이메일 인증을 켜 두는 것을 권장합니다.

## 2. 앱에 Supabase 연결값 넣기
`supabase-config.js` 파일을 메모장 또는 코드 편집기로 열어 아래 두 값만 입력합니다.

```js
window.SUPABASE_CONFIG = {
  url: "https://프로젝트ID.supabase.co",
  anonKey: "여기에_anon_public_키"
};
```

저장 후 파일을 닫습니다. 비밀 `service_role` 키는 사용하지 않습니다.

## 3. GitHub Pages로 홈페이지 게시
1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다. 예: `family-hiking-journal`
2. 이 패키지의 파일 6개(`index.html`, `styles.css`, `app.js`, `manifest.json`, `supabase-config.js`, `supabase_schema.sql`)를 저장소 최상위에 업로드합니다. README도 함께 올려도 됩니다.
3. 저장소 `Settings` → `Pages`에서 `Deploy from a branch`를 선택하고 `main` 및 `/(root)`를 지정해 저장합니다.
4. 잠시 후 만들어진 `https://계정명.github.io/저장소명/` 주소로 접속합니다.
5. Supabase `Authentication` → `URL Configuration`의 Site URL 및 Redirect URLs에 위 HTTPS 주소를 등록합니다.

## 4. 관리자 계정 등록 (중요: 가족보다 먼저)
1. 새 홈페이지 주소를 열고 `처음 가입`을 눌러 관리자 본인의 이메일과 비밀번호로 가입합니다.
2. 이메일 인증 메일이 오면 인증을 완료합니다.
3. 홈페이지에서 관리자 계정으로 로그인합니다. 최초 로그인 계정이 관리자 권한으로 등록됩니다.
4. 로그인 후 `가족 관리` 버튼이 보이는지 확인합니다.

**주의:** 이 최초 관리자 등록이 끝나기 전에는 가족에게 계정을 만들거나 홈페이지를 공유하지 마세요. 소유자 등록은 비어 있는 기록장의 첫 로그인 계정을 관리자로 지정하도록 설계되어 있습니다.

## 5. 가족 계정 추가
1. 가족이 홈페이지에서 `처음 가입`을 눌러 각자 이메일과 비밀번호로 가입합니다.
2. 가족이 이메일 인증을 완료하고 한 번 로그인합니다.
3. 관리자는 `가족 관리` → 가족 이메일 입력 → `가족 추가`를 누릅니다.
4. 이후 가족은 같은 홈페이지 주소에서 자신의 이메일 계정으로 로그인하면 기록과 사진을 열람할 수 있습니다.
5. 접근을 중단하려면 관리자가 `가족 관리`에서 해당 계정의 `접근 해제`를 누릅니다.

## 6. 기존 산행 기록 옮기기
1. 기존 기록이 저장된 브라우저/기기에서 기존 산행기록장을 엽니다.
2. `백업 / 복원` → `백업 내려받기`를 눌러 사진 포함 JSON 파일을 저장합니다.
3. 새 클라우드 홈페이지에 관리자 계정으로 로그인합니다.
4. `백업 / 복원` → `백업 파일 복원`에서 JSON을 선택합니다.
5. 산행 기록과 사진이 클라우드에 올라갔는지 확인합니다. 사진 수와 기록 수를 대조한 후 기존 백업 파일을 안전한 곳에 보관합니다.

기존 기록이 여러 브라우저에 나뉘어 있다면 각 브라우저에서 별도로 백업해야 합니다. 사진이 포함된 JSON은 용량이 클 수 있습니다.

## PC와 스마트폰에서 사용하기
- PC와 스마트폰 모두 같은 HTTPS 홈페이지 주소를 엽니다.
- 각 기기에서 같은 계정으로 로그인하면 동일한 클라우드 기록을 읽고 수정할 수 있습니다.
- 기록 변경은 Supabase Realtime을 통해 열려 있는 다른 기기에도 전달되도록 설정되어 있습니다. 네트워크 상태에 따라 반영까지 약간의 시간이 걸릴 수 있습니다.
- 스마트폰 브라우저 메뉴의 `홈 화면에 추가`를 사용하면 앱처럼 실행할 수 있습니다.

## 사진 및 보안
- 사진은 브라우저에서 JPEG로 축소한 뒤 비공개 `hike-photos` 저장소에 업로드합니다.
- 가족 계정은 초대된 기록과 사진을 읽을 수만 있습니다.
- 관리자만 기록 및 사진을 생성·수정·삭제할 수 있습니다.
- 비밀번호, `service_role` 키, 이메일 인증 링크를 타인과 공유하지 마세요.
- 정기적으로 `백업 내려받기`를 실행해 별도 보관하는 것을 권장합니다.
