SYNC GUIDE

회사 PC·스마트폰에서 함께 쓰기

ChatGPT 라이브러리는 원본 파일 보관에는 유용하지만, 저장한 파일을 웹앱처럼 실행하거나 기록 데이터베이스로 자동 동기화하지는 않습니다.

  1. 앱 파일을 웹에 게시압축 파일 안의 안내서에 따라 GitHub Pages 등 HTTPS 웹 주소로 게시합니다.
  2. 클라우드 저장소 연결같이 제공한 Supabase SQL과 설정 파일을 한 번 연결하면 산행 기록·사진을 계정에 저장할 수 있습니다.
  3. 두 기기에서 같은 주소로 로그인회사 PC와 스마트폰에서 같은 웹 주소와 계정으로 접속하면 기록이 동기화됩니다.

지금 상태는 브라우저별 저장 모드입니다. 클라우드를 설정하기 전에는 회사 PC의 기록이 스마트폰에 자동으로 나타나지 않으니, 백업 파일도 함께 보관하세요.
